# Retro ROMs Directory

Place your legal Game Boy (.gb), Game Boy Color (.gbc), and Game Boy Advance (.gba) ROM files in this directory.

### Supported Systems:
- **Game Boy / Game Boy Color:** Powered by injgb WebAssembly engine with 60 FPS audio/video synchronization and persistent battery SRAM auto-saving.
- **Game Boy Advance:** Powered by gbajs with 800x480 landscape aspect-ratio rendering and full physical button/rotary dial support.

### Controls on Spotify Car Thing:
- **Rotary Dial Turn:** Left / Right / Page Scroll
- **Rotary Dial Push:** Button A / Select
- **Physical Back Button:** Button B / Back
- **Top Preset Buttons 1-4:** Start / Select / Turbo / Menu
- **Touch Screen:** On-screen responsive D-Pad, A/B buttons, and Save state menu

### Preloaded Homebrew Games:
- celeste.gba - Celeste Classic GBA port (Open Source)
- dvancetris.gba - Advancetris GBA homebrew (Open Source)
- nguna.gba - Anguna: Warriors of Virtue action-adventure (Open Source)
