# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Car Thing Apps is an offline, hobbyist open-source project designed for personal hardware tinkering. 

If you discover a security vulnerability or sensitive disclosure issue, please report it responsibly:
1. Open a confidential GitHub Security Advisory on this repository, or
2. Open a private issue describing the vulnerability and reproduction steps.

Please do not disclose vulnerabilities publicly until a patch or mitigation is available.
